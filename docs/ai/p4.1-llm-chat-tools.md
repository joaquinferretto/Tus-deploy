# P4.1 LLM, Chat, Structured Output, and Tools

The Python LangGraph worker owns the P4.1 AI ports. JSON Schema contracts are
versioned under `packages/ai-contracts/schemas/{llm,chat,structured-output,tools}`
and carry tenant, actor, correlation, and root-lineage metadata.

## Provider behavior

- `DeterministicLLM` and `DeterministicChat` are provider-free local fakes.
- `GroqLLM(active=True, transport=...)` is the active-provider shape. The
  transport is injected so local tests never call Groq.
- `GroqLLM(active=False)` is activation-gated and fails closed with
  `ProviderUnavailableError`; it does not silently switch providers.
- AWS/Bedrock is not implemented by P4.1 and remains outside this slice.

## Structured output

`StructuredOutputExecutor` validates parsed JSON with the caller's JSON Schema.
Invalid JSON and schema failures are returned as a failed typed result after at
most three attempts. Usage is accumulated across attempts and no unbounded
retry is allowed.

## Permissioned tools

`PermissionedToolExecutor` requires an explicit tenant/actor grant for the
tool's permission. Denied and invalid invocations never execute the handler and
produce deterministic audit metadata containing the decision, reason, tenant,
actor, correlation, idempotency, and lineage fields.

All local evidence is deterministic. No provider, cloud, database, credential,
secret, or `.env` access is required or claimed.
