# Product Factory Core Final Traceability

## Scope and truth boundary

This is the P6.9 final traceability index for the approved `product-factory-core`
roadmap. It is generated from the current OpenSpec scenario set, the governance
capability ledger, the P2.11 machine ledger, the AI catalog ledger, and the P6
activation catalog. Every row names the implementation boundary, deterministic
fake or fixture, focused test, owner/config source, evidence record, and rollback
boundary. A row being traceable does not promote an unavailable provider or
profile to production readiness.

`liveConformance: false` is the current repository-wide disposition. No live
cloud, provider, database, credential, secret, or `.env` access was used for this
artifact. Authorized cloud smoke remains `unavailable-deferred`; plan fixtures,
deterministic fakes, and local tests are not live conformance.

P0.6b, P2.L1–P2.L14, and P4.16+ remain explicitly deferred and outside this
final traceability claim. P0.6b is retained as an optional future Compose slice.
