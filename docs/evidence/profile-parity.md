# Profile parity evidence

## Scope

This record covers the deterministic P6.6 portability check for the two active
cloud-native profiles. It does not provision resources, contact Render or AWS,
connect to a database, read `.env`, inspect credentials, or claim live
conformance. Compose/P0.6b remains deferred and non-blocking.

## Render/AWS parity matrix

The infrastructure authority and configuration reference are intentionally
profile-specific. Ownership, rollback, fake/disabled disposition, and
activation-gate semantics must remain shared.

| Boundary       | Render-native                                 | AWS Terraform                                                    | Shared parity contract                                                                                                                                     |
| -------------- | --------------------------------------------- | ---------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------- |
| PostgreSQL     | Render secret-store reference; Neon boundary  | AWS Secrets Manager reference; RDS/Aurora decision boundary      | Data Platform owner; last passing schema and verified backup; disabled until endpoint; endpoint, secret reference, backup, quota, authorized smoke         |
| MongoDB        | Render secret-store managed MongoDB reference | AWS secret-store/approved Atlas or DocumentDB decision reference | Document Data owner; restore/rebuild with reconciliation; deterministic document fake; owner, network, retention, backup, authorized smoke                 |
| Redis          | Render secret-store managed Redis reference   | AWS Secrets Manager/ElastiCache reference                        | Runtime Jobs owner; disable consumers and replay ledger; deterministic cache/queue fake; retry, quota, secret reference, authorized smoke                  |
| Object storage | Render/B2 profile reference                   | Terraform S3 output reference                                    | Assets owner; reconcile versioned objects; deterministic object fake; policy, encryption, lifecycle, authorized smoke                                      |
| Queues         | Render-managed queue reference                | Terraform SQS/DLQ output reference                               | Runtime Jobs owner; stop intake and replay ledger/outbox/DLQ; deterministic transport fake; queue policy, retry, secret reference, quota, authorized smoke |

The machine-readable matrix is generated by
`scripts/validation/portability/index.mjs` from the existing cloud-native
boundary contracts. The validator compares the shared fields and returns
`status: "pass"` only when both profiles expose all five boundaries without
divergence.

## Deterministic result

Expected local result for this repository:

```json
{
  "version": "portability.v1",
  "valid": true,
  "liveConformance": false,
  "parity": {
    "status": "pass",
    "unsupportedProfiles": []
  },
  "cloud": {
    "kind": "cloud-plan-validation",
    "liveConformance": false
  },
  "compose": {
    "status": "deferred",
    "liveConformance": false
  }
}
```

The deterministic tests also mutate a synthetic profile to prove that a
rollback divergence produces `status: "unsupported-profile"` and names the
affected profile. They mutate the clean-checkout fixture to prove that
maintainer-only knowledge or an unsupported profile selection fails without
any external call.

## Contamination scan

The result includes the P5.6 neutral-core contamination scan. The scan must
remain valid with no vertical vocabulary, fallback imports, or client policy
bypasses. A finding fails portability evidence; it is not hidden by a passing
cloud plan.

## Runtime and authorization disposition

Only committed synthetic fixtures are evaluated by this evidence. Terraform
execution, Render dry-run against a provider account, AWS plan against a
provider account, managed databases, and authorized smoke are unavailable
unless separately approved and supplied with matching evidence. No such live
claim is made here.
