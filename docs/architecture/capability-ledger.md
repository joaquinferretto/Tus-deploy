# Capability Ledger

This ledger is the governance source for bounded delivery. Every row has one
owner, one dependency phase, one contract boundary, one implementation path, a
deterministic local fixture, a neutral use case, explicit security/data/cost
ownership, and an independently verifiable evidence gate. Later phases remain
disabled until their rows are independently verified. Evidence is
profile-specific: native local smoke is not cloud conformance, and cloud plan
validation is not authorized live smoke.

## P2.11 Traceability Ledger

The P2.11 contract is the machine-readable source for these fourteen Phase 2
rows. Each row is independently scoped and carries an owner, evidence gate,
activation or deferred decision, and rollback reference. Local deterministic
evidence does not claim live PostgreSQL, Redis, queue, object-storage, email,
cloud, or provider conformance.
