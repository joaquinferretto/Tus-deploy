# Publicar servicios

1. Completá tu perfil de prestador (zona, categoría y política de trabajo).
2. Creá el servicio: nombre, descripción, forma de precio (fijo, desde o con presupuesto) y modalidad (turno fijo,
   visita de diagnóstico o con presupuesto).
3. Configurá tu agenda si el servicio se reserva por horario.
4. Publicá el servicio. Para publicar necesitás tener tu identidad verificada.

Los clientes ven solo los datos públicos del servicio; tus datos de contacto no se muestran.
