# Publicar servicios

1. Completá tu perfil de prestador y elegí en [Perfil público](/prestador/perfil-publico) los servicios que ofrecés,
   del catálogo de TUS.
2. Cada servicio tiene una duración y un precio. Un servicio puede tener variantes (por ejemplo una sesión corta y una
   larga), cada una con su duración y su precio.
3. Configurá tu [disponibilidad](/ayuda/prestadores/disponibilidad) si el servicio se reserva por turno.
4. Para publicar servicios y aceptar trabajos necesitás tener tu identidad verificada.

Los clientes ven solo los datos públicos del servicio; tus datos de contacto no se muestran.

## Precios

El precio que ve el cliente es el que está cargado para ese servicio (o para la variante que elige). Con ese precio TUS
calcula la seña de un turno. Un servicio sin precio cargado no puede recibir solicitudes de turno con seña.

El precio vigente de cada servicio lo informa siempre TUS en el momento: este manual no lo fija. Si necesitás cambiar el
precio o las variantes de un servicio y no encontrás la opción en tu panel, pedíselo al equipo de TUS.

## Turno por turno

Al cargar un turno manual desde [Turnos](/prestador/turnos) podés indicar un precio final para ese turno en particular.
