# Presupuestos

Algunos servicios no tienen un precio cerrado: el prestador primero hace un diagnóstico y después envía un presupuesto
con el alcance del trabajo, el detalle y el total.

## Aceptar o rechazar un presupuesto

El cliente puede aceptar o rechazar cada presupuesto. Para rechazarlo tiene que indicar un motivo. Si el prestador envía
una versión nueva, la decisión se toma sobre esa versión.

## Qué se paga

El cliente paga exactamente el total del presupuesto aceptado. Sin presupuesto aceptado un servicio que lo requiere no se
puede pagar.

Por WhatsApp podés consultar tus presupuestos y aceptarlos o rechazarlos, siempre con una confirmación explícita antes
de que se registre la decisión.
