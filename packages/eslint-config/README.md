# @repo/eslint-config

Shared ESLint configuration for the monorepo.

## Usage

### For Next.js apps:
```js
// .eslintrc.js
module.exports = {
  extends: ['@repo/eslint-config/next'],
}
```

### For Node.js/Express apps:
```js
// .eslintrc.js
module.exports = {
  extends: ['@repo/eslint-config'],
}
```
